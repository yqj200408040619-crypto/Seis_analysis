第 1 步：下载、解压和摆放目录

  1. 下载 Studio_v2_2_Program.zip，先右键“全部解压”。不要直接在压缩包内双击 BAT。
  2. 建议将解压出的 NoiseDispersionStudio_v2_2 放在 C:\Seismic\，确认该目录同时包含 run.py、ndstudio、core、三个 h5data 脚本及安装/启动 BAT。
  3. 将 Studio_v2_2_Results.zip 解压到另一个目录，如 C:\Seismic\saved_results。其中的 DARE_真实端到端 和 Dublin_真实端到端 是两个独立项目。
  4. 新计算建议单独建 C:\Seismic\runs\。项目目录、原始 H5 目录和程序目录分开，便于保留原始数据与既有结果。

重新整理的程序包保留全部程序源码、GUI、模板、测试与示例生成器。为减小下载体积，不重复携带旧的合成 H5 和旧示例计算输出；需要演示数据时可由程序自己生成。真实 H5 因体积较大，仍单独按 UTC 日提供。

下载大小不是解压大小。结果包完整保留 CSV、JSON、图件、配置、审计、筛选和失败尝试；解压时留足空间。SHA256 校验和文件大小随下载包提供。

第 2 步：Windows 安装与启动

  1. 安装 64 位 Python 3.12，安装时包含 Python Launcher（py）。
  2. 双击程序目录中的 install_windows.bat。它会建立该目录的 .venv 并安装 requirements.txt。首次安装需要联网，等到显示 Installation complete。
  3. 做与本次真实测试相同的独立正演核对，还需安装 requirements-optional.txt。在程序目录空白处右键“在终端中打开”，执行下面的可选依赖命令。
  4. 执行 doctor 检查依赖。全部主要包应显示版本号；若勾选“要求pysurf96独立求解器通过”，pysurf96 必须存在。
  5. 双击 run_download_windows.bat 打开下载器；双击 run_windows.bat 打开分析 GUI。

本手册的 Windows 命令都在程序目录运行，并明确使用 .\.venv\Scripts\python.exe。这样无需激活 PowerShell 脚本，也不会误用另一套 Python 环境。doctor 只检查包能否导入；它显示 NOT INSTALLED 时要看缺少的具体包，不能仅凭命令退出就判断环境完整。

.\.venv\Scripts\python.exe -m pip install -r requirements-optional.txt
.\.venv\Scripts\python.exe run.py doctor
.\.venv\Scripts\python.exe -c "import ndstudio; print(ndstudio.__version__)"
.\.venv\Scripts\python.exe run.py download
.\.venv\Scripts\python.exe run.py gui

pysurf96==1.0.1 包含编译扩展，部分平台安装会要求编译环境。安装失败时保留终端错误，先解决该依赖后再要求独立核对；不安装它可运行波形和频散流程，普通 GUI 中未要求独立核对时只能形成相应标注的探索性结构。真实阵列复现驱动始终要求独立核对。

Linux / macOS在程序目录建立环境后使用下面命令。GUI 需要可用的桌面显示环境。
python3.12 -m venv .venv

第 3 步：下载前预览阵列与平均台站间距

以下为下载器的 Arrays 页。也可从分析 GUI 顶部点击“下载数据 / 阵列预览”进入。

  1. Provider：选择数据所在服务；本次两轮用 GFZ。切换 Provider 后必须重新查询。
  2. 在 Network / array 填台网代码，如都柏林 1V 或 DARE Y7。Stations (sub-array) 填 * 查询全部，或输入已确定的台站过滤条件。
  3. 点击 List arrays，再单击返回的阵列行，等待下方台站表和阵列图出现。仅选中上方阵列还没有开始下载。
  4. 查看下方每台站的坐标、Rate (Hz)、Sensor 和历元，确认是目标宽频带仪器和垂直通道。Channels 建议先选 HHZ；若数据服务实际提供 BHZ，就选 BHZ。
  5. 在下方 Time window 选 Custom，填写 Start (UTC) 和 End (UTC)。这是 UTC，不是电脑本地时间。都柏林例子为 2019-04-01T00:00:00 至 2019-04-05T00:00:00。
  6. Chunk size 选 1 day。Output folder 选准备保存原始 H5 的目录。
  7. 检查图下蓝色 Mean station spacing 与台站数量。平均间距为每台到最近另一台的 WGS84 地表距离平均值，单位 m；All-pair mean 是全部台对平均距离，二者不同。
Arrays 页面列出的是当前过滤后的阵列。点击“Download entire array”会下载当前阵列过滤条件所含的全部通道，并不是只下载台站表中高亮的一行。如果只取任意几台，请改用下面的 Channels 页逐行选择。

Channels 页：手动选择一个子阵列

  1. 切到 Channels；填 Network、Station、Location、Channel。
  2. 点击 Browse 查询。使用 Ctrl 单击多选，或 Shift 选择连续行；同一台站不要选多个重叠历元当作不同台站。
  3. 观察选中通道对应的阵列图、数量和平均间距；再点击 Download selected。

台数限制与几何自动筛选属于命令行选站器。GUI 预览会显示几何，但不会自动强制“5–100 台且每台最近邻 200–2000 m”。需要严格约束自动选站时，请用本手册“完整复现 / 内置选站命令”部分。

第 4 步：开始下载、保存完整 H5 并进入分析

  1. 保持 H5 + full metadata 勾选。保留 Resume: skip files already downloaded 勾选，以便中断后继续。
  2. 根据上一步的选择方式点击 Download entire array 或 Download selected。
  3. 确认对话框中的台站/通道数、日期、分块和输出位置，再开始。等待 Status 和日志结束；若有 skipped / errors，逐项看原因。
  4. 在输出目录确认已经出现 .h5。H5 保存原生 counts、实际样点 UTC、采样率、NSLC、坐标、历元、完整 StationXML 和原服务器 MiniSEED 字节。文件名请求日期不一定等于第一实际样点，程序使用 H5 内 UTC。
  5. 点击 Open H5 in dispersion，进入已指向该 H5 文件夹的分析项目。下载器自动在输入目录旁创建或复用 <输入目录名>_dispersion_project；例如输入为 my_array/download，项目为 my_array/download_dispersion_project。如果已经由此打开项目，下一步直接从“扫描与识别”继续，无需重复新建。若你自己启动了分析 GUI，再按下一步另建项目并选择同一输入目录。

网络失败时保留原输出目录，重新用相同参数和 Resume 重试。服务器明确“no data”与网络错误是两类情况：前者没有对应 H5，应检查日期/历元并记录缺失；后者需重试。不要把“任务结束”解释为“全部请求都有波形”。都柏林原始下载的 G012、G020 返回无数据，已经在清单中记录。

内置下载后的 H5 自带完整响应，通常无需再点“统一设置StationXML”。如果改用你自己的旧 HDF5，响应是否完整必须逐条核对。

.\.venv\Scripts\python.exe run.py acquisition-audit --folder "C:\Seismic\runs\my_array\download"

以上可选审计命令只针对本程序下载格式，核对 H5 中样值、实际 UTC、采样率、原始 MiniSEED 和 StationXML。一般自定义 HDF5 请先走映射与导入，不应把 acquisition-audit 当作所有 HDF5 的通用识别器。

第 5 步：新建项目、扫描 H5、补齐映射

  1. 打开分析 GUI，点击顶部 新建项目，选择一个新项目目录，如 C:\Seismic\runs\my_array\project。新建项目会生成 project.json、config.json 和 mapping.json。
  2. 在 1 输入与映射 页，点击 选择文件夹，选原始 H5 的父目录。程序递归扫描子目录，不必逐台选择。
  3. 点击 扫描与识别。等下方任务结束，查看数据集表“状态”列与底部字段完整提示。
  4. 若有待补字段，单击对应行，再点 编辑所选映射；也可双击该行。填完按 Save，程序重新扫描。
  5. 确认保留的数据集“使用”列被勾选。确实不用的整条记录可取消勾选；长期异常台站可在“排除台站”中填项目标签。
  6. 点击 仅导入与核查，等待完成。这一步必须先于“仅预处理”；扫描只识别格式，不会生成可处理的 canonical 数据。
  7. 点击 查看输入质量表，结合仪器记录查看近常数或大直流提示。GUI 的质量表给出提示，不会自动替你排除所有异常站。
映射字段应该填什么常见错误
station / station_label / seed_id原始台站代码；跨台网项目标签；完整 NSLC，如 1V.G003..HHZ无 Location 时 NSLC 仍有两个相邻点
sampling_rate_hz原生采样率，如 100；不是第 2 页的分析采样率不要把原生 100 Hz 写成处理后的 20 Hz
start_utc / time_format第一实际样点 UTC；数值时间明确 unix_s/ms/us/ns不能使用文件修改时间，也不能让多个文件共用猜测 UTC
unitscounts / m/s / m/s^2 / m，必须与真实数据一致不能把 counts 直接标成已校正 m/s
坐标所有台站统一用经纬度，或同一参考系的 x_m/y_m不要混用度和米或混用多个本地原点
response_xmlcounts 必须匹配真实 NSLC 和记录历元；本版内嵌响应自动读不同传感器不能随意套同一个响应
sample_axis / component_index二维矩阵需确认采样轴和垂直分量索引，索引从 0 起三分量不是三台站；不能猜矩阵方向
clock_offset_s / polarity_verified有独立依据才填授时改正、勾选现场极性已核实默认 0 或 +1 是假设，不等于现场已校准

“排除台站”填写导入质量表 station 列中的完整项目标签，如 1V_G011,1V_G015，不要仅凭文件名猜代码。修改映射、取消记录或改变排除列表后，重新“仅导入与核查”，再从预处理开始重跑。

导入完成后检查项目根目录的 stations.csv、input_station_qc.csv 和 hdf_import_audit.json。原始 H5 只读；仅数值和 UTC 网格完全相同的重叠才去重，冲突重叠会明确拒绝。

第 6 步：设置频段、时间窗和质量门限

切到 2 分析设置。先新建/打开项目，再看控件值；下表是新建 Studio 项目及两次真实测试采用的常用值，不是适用于所有地质条件的自动答案。

界面控件 / 配置这两轮采用的值操作含义
频率下限 / 上限 / 扫描步长1.5 / 5.0 / 0.01 Hz控制相位扫描频率；不是带通滤波的两个边界
分析采样率20 Hz原生 100 Hz 记录在处理阶段重采样，原始 H5 不改写
共同去前600 s相同时间轴起点后舍弃 600 s，不是每个文件各删 600 s
分析窗 / 连续干净片段1200 s / 600 s20 min 窗；须有足够共同连续有效样点
共同干净比例0.7多台站共同有效比例；台站越多，交集可能越小
开发/验证 SNR 门槛10不能因结果少就把检验门限降下来
尖峰 MAD / 最大修复时长18 / 0.04 s只修复允许时长的局部尖峰，其他异常通过局部掩码处理
bandpass_hz（高级 JSON）[0.1, 7.142857142857] Hz处理带通，需包围扫描频带

cohorts / phase（高级 JSON）states=0；cycle_min=0，cycle_max=200；源相位 π/4不分 PCA 状态；逐段枚举固定周期，源相位是明确假设
验证时间块（高级 JSON）21600 s；至少 4 个 eligible blocks，每块至少 6 窗还需训练/验证各至少 12 窗；只看总窗数不够
  1. 常用控件改完点 保存常用参数。
  2. 要修改带通、响应预滤波、验证块或周期上限，编辑右侧 JSON，再点击 保存高级JSON并同步常用参数。仅在文本框里改字但未保存，不会成为下一次实际配置。
  3. 保持 导入后自动核对几何并调整到时/噪声区 勾选。它会按台数和距离调整到时搜索、噪声区与连续窗，不会自动替你确认物理频散或降低质量门限。

导入后几何适配可能改变最大时延或窗参数；以落盘 config.json 为准。本次 DARE 最大时延为 62 s、都柏林为 61 s。到时超过自动适配支持范围会报错，此时要重新核对阵列尺度或明确调整高级配置。

频率必须满足 0 < 带通下限 < 扫描下限 < 扫描上限 < 带通上限 < 分析采样率/2。响应预滤波四角还必须包围带通并低于 Nyquist。若想分析更低频，不能只改一个扫描下限；必须协调带通、响应、窗长和相应验证尺度。

第 7 步：按按钮逐阶段处理，或一键分析

首次处理建议按下面顺序逐步执行。运行时页面暂时禁用，进度条可能表示正在忙；不要把暂时没有新曲线理解成程序卡死。看底部阶段名、日志和完成状态。

“一键分析”怎样用

  1. 先选好 H5 文件夹、映射、排除台站和参数。下载不是“一键分析”的一部分。
  2. 在第 4 页设置自动组数上限及模态；首次可用 12，检验更多候选可用 1000。
  3. 需要自动反演时，保留下方 分析完成后自动组合并反演（条件假设） 勾选，再点 一键分析。未勾选时只完成波形/候选/报告等分析。
  4. 完成后看各阶段状态及实际模型数量。没有可用自动组时，程序可记录跳过反演并生成报告；没有通过结构时也可正常完成拒绝记录。
GUI 一键分析 ≠ 真实测试复现驱动。GUI 按你选好的台站运行处理；本版 GUI 没有独立的 array-select、screen-array 或 screen-prepared 按钮，不会在失败后自动实施复现驱动的时域子阵列筛选。需要这套自动筛选流程请看第 12 步。

点击 停止 会终止当前阶段。中间文件/模型检查点不等于完整完成结果。重新计算必须沿依赖顺序推进，不能跳过失败阶段直接跑反演。

第 8 步：查看频散候选并选择反演组

  1. 切到 3 候选曲线，点 刷新结果。
  2. 表格默认最多显示 300 行；想看都柏林 301 条就把 最多显示 调到至少 301。DARE 有 1470 条，默认只显示前 300，并不是其余候选丢失。
  3. 在搜索框输入 curve_id、台对或时间组；点击一行看右侧曲线，Ctrl/Shift 多选比较。图通常最多同时画 30 条；完整 CSV 始终保留全部曲线。
  4. 读清 cohort（all / day / night）、branch、constant_cycle 和频段。点一条时虚线群速度用于对照。
  5. 选定假设 Rayleigh 模态，0 为基阶。若每条是相互竞争的解释，点 所选各自建组；要检验共同 1D 结构才点 所选联合建组，并核对是否同一时间组、不同台对和相同源相位假设。

conditional_dispersion.csv 不是唯一物理频散曲线。每个连续相位段采用一个固定整数周期及源相位假设；排序和跨台对兼容数不等于概率。两种全天/夜间结果可能共享原观测，不能当作完全独立观测重复计权。不同候选速度不能仅凭更接近期待值就认定周期。

第 9 步：设置和运行条件结构反演

  1. 切到 4 条件反演。上方 自动组数上限 控制要检验多少个自动组，不是每组频点数或输出模型数。默认 12。
  2. 自动假设模态，如0,1 中填 0 可只检验基阶假设。多模态增加的是待检验假设，不意味着模态已由数据证明。
  3. 有限层数（另加半空间） 填 1,2，表示分别检验 1 个有限层和 2 个有限层，两者都另加下方半空间。
  4. 设置起点数、最大评价次数、Vp/Vs、密度及三个误差门限。复现本次测试采用下表值。
  5. 要独立核对时勾选 要求pysurf96独立求解器通过，并确认安装了可选依赖。
  6. 自动组路线：先点 自动组合，核对右侧组 JSON；人工组路线：保留第 3 页生成的各组，别再点“自动组合”覆盖它。
  7. 需要手动改组 JSON 时，改完点 保存反演设置与组JSON。反演时左侧常用控件会写入 settings，同名参数请在左侧改；层厚/速度上下界等未显示控件的高级字段可在 settings 中改。
  8. 点击 运行选定组反演，等待该阶段结束。下方表格显示通过条件的模型；完整拒绝尝试也会保存。

逐层深度表：一个模型一组行

用 model_id 筛出同一个模型。第一有限层 top_depth_m=0；下一层的顶部为上层底部；bottom_depth_m = top_depth_m + thickness_m。layer_type=halfspace 的 thickness_m 与 bottom_depth_m 留空，表示延伸半空间，不是零厚度。

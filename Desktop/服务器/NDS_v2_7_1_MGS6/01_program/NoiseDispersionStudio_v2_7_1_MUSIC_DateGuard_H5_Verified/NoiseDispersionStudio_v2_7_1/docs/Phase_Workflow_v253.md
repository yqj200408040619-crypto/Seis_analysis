# v2.5.3：完整记录、逐频时窗与 MATLAB 分支叠加

第6页现在直接处理每对台站的全部共同记录。开始/结束UTC原来是截取记录的边界，不是单窗长度；默认不再要求填写，旧设置里未标明time_mode的短区间也不会限制新版界面。

按用户附件的框架，默认在各台站对的共同起点顺延600秒，然后使用该对剩余全部共同时长。稳定时间可设为0。全记录时间轴来自已经导入的波形头信息，不受旧CCF扫描时间范围、其他台站对的更短记录或候选曲线原时段的限制。结束UTC为不含该时刻的边界。

| 步骤 | 新版行为 |
|---|---|
| 逐频时窗 | T=N/f，滑动Δt=M/f，取整到采样点；默认20周期/1周期 |
| Goertzel | 去均值；默认最近DFT频点，与附件一致；可选精确曲线频率 |
| 幅值筛选 | 默认MAD剔除幅值和突变异常；取消复选框时只标记 |
| 分支 | 按原互谱相位≥0°与<0°分开，保持复数符号，不共轭或反号 |
| 曲线模式 | 每个频点速度、台距、源相位及CCF分支给出相位门限 |
| 附件原门限模式 | 各相位分支初叠加相位±90° |
| 最终相位 | 各分支arg(ΣC)，另存等权相位arg(ΣC/\|C\|) |

两种模式使用同一套完整记录/窗口/互谱/MAD/分支框架，区别在相位门限来源。曲线主结果取预测相位同号分支，两分支完整结果保存在phase_branch_summary.csv。相位正负与CCF时延正负分支不同，不能混用名称。

最近DFT频点fk可能与曲线f略有差异，界面和CSV同时显示二者。需要严格逐频对应时选择精确频率。幅值权重会影响原始互谱叠加；两种叠加相位与两分支结果均可核查。筛选后的集中相位不能独立证明输入频散正确。

验证：163项完整回归通过，12项因Tk显示环境或可选独立求解器缺失跳过；最终9项工作流测试通过。实际Qt子进程在未填UTC的情况下处理完整原始波形，验证每对台站独立起点、缺测、6小时块边界与旧设置迁移。

真实DARE校正数据覆盖30分钟，默认稳定600秒后遍历余下20分钟。两种模式均核对264个逐频任务、重算792个真实窗口互谱。附件原门限模式的1195528个窗口掩码全部与独立实现一致；标量Goertzel对照最大相位差约7.12e-14 rad。没有执行MATLAB或Windows原生运行时，也未重下载四天完整数据。

可运行程序自带离线示例：run_dare_phase_test_windows.bat。查看附件原门限时，把示例settings.json的screening_mode改为matlab并另设输出目录，再运行：

```text
python examples/check_matlab_phase.py --folder YOUR_MATLAB_MODE_OUTPUT
```

# v2.5 单台 H/V 与浅层结构分析

现在有两条分析入口：原有多台站垂直分量频散，以及新增单台三分量 H/V。H/V 不要求至少两个台站，不经过台对距离、到时搜索或 40 秒到时检查。

## 下载后如何使用

1. 打开原来的下载窗口，选择台站和 UTC 时间范围。
2. 下载同一仪器的 **三个分量**。例如查询/筛选 `HH?`、`BH?` 或选择具体 `HHN,HHE,HHZ`；只下载 `HHZ` 无法计算 H/V。三分量须有相同台网、台站、位置代码、通道族和采样率。
3. 保持 **H5 + full metadata** 勾选。下载文件保留原生数据和完整内嵌 StationXML。
4. 下载结束点击 **Open single-station H/V**。程序创建/打开单台项目，进入 **7 单台 H/V 与浅层** 页面。
5. 点击“列出仪器 / 检查三分量”，选择一台仪器，设置频率范围、窗长与 Vs 先验，再点击“计算 H/V 与浅层结构约束”。本页底部“一键 H/V 分析”也是同一入口。
6. “打开 H/V 离线报告”显示曲线、分量谱、时窗变化、峰质量表和浅层结构约束。

也可以从主窗口新建项目，在第 7 页直接选择已有下载 H5 文件夹。无需先执行第 1 页的多台站“导入与核查”。台对分析和 H/V 各自保存参数。

## 参数怎样设置

| 目标最低频率 | 建议起始窗长 | 理由 |
|---|---:|---|
| 1 Hz | 30–60 s | 至少保留 10–20 周期，观察窗间稳定性 |
| 0.2 Hz | 120 s | 每窗约 24 周期 |
| 0.05 Hz | 400–600 s | 低频需要更长的稳定记录与低噪声仪器 |

这些是调参起点，并不保证质量通过。总记录必须提供足够多个互不重叠的有效窗。输入单位为 counts 时，每侧额外读取默认 `3/fmin` 秒响应缓冲；记录边缘或缓冲区有缺测的窗会跳过，因此有效窗可能少于记录长度/窗长。

- 频率上限必须小于原始采样率的 0.45 倍，保留响应预滤波余量。
- 默认窗长 60 s、重叠 0、K–O 平滑 b=40。重叠窗用于展示，但统计与周期计数只用互不重叠的有效窗。
- 默认水平合成 `rms`: `sqrt((|N|²+|E|²)/2)`；还提供 `geometric` 和 `total`。先合成原始 Fourier 水平幅值再 K–O 平滑；RMS/total 保持水平旋转不变。几何平均会依赖水平坐标方向。
- `frequency_points` 只控制输出网格，不能增加实际 FFT 分辨率。
- 默认剔除原波形突发噪声；峰频率、H/V 相似性不用于筛窗，以免人为集中峰。异常原因逐窗写入 `window_qc.csv`。
- 不做 one-bit、逐窗幅值归一化或谱白化；这些操作会改变需要保留的水平/垂直幅值关系。
- 如已明确仪器时钟偏差，可通过 H5 的 `clock_offset_s` 使用元数据给出的修正。程序不从波形自行估计时钟偏差。

## 数据支持和质量控制

- 直接支持本程序下载的 1D H5 波形数据集；通用 1D 数据需声明 `seed_id`、原生采样率、UTC、单位和校正状态。
- 每个数据集对应一个分量。二维三分量数组目前须先按明确分量次序导出为三个 1D 数据集；第 1 页频散映射不会自动用于 H/V。
- 原始 counts 必须具有完整 StationXML，每分量各自校正到速度；不同增益不会被假定抵消。响应历元必须覆盖原始记录，窗内响应改变会拒绝拼接。
- 已校正输入要求 `precorrected=true`，三分量物理单位一致，支持 `m/s`、`m/s^2`、`m`。不要把 counts 改名为物理单位。
- 有 `azimuth_deg` / `dip_deg` 时，通过完整方向矩阵恢复 N/E/向上 Z。`1/2/Z` 需要方向元数据；缺方向的 N/E/Z 才使用通道命名惯例，并在报告记录提醒。共线或近奇异方向矩阵不接受。
- 缺测、非有限值、零信号、冲突重叠、非同网格 UTC、明显双端限幅会拒绝该窗。相同样点的重复重叠允许去重。保留原生样点，不自动重采样或填缺测。
- 默认突发门限：峰值/RMS 12，1 秒块 RMS/块 RMS 中位数 4；高级参数可调。这不是通用仪器噪声底判据。

峰检测要求超过 1.2 且局部峰具有至少 10% 对数显著度，避免把平坦曲线数值波动当峰。逐项输出 SESAME 的 3 项可靠性与 6 项清晰度检查；另检查至少 80% 统计窗在同一局部分支有峰。可靠性全通过且清晰度至少 5/6 为清晰峰评分条件。v2.5.1 自动结构估计还要求峰两侧均观测到充分下降：这是程序额外的解释保护，不改变 SESAME 的 5/6 标准。只有单侧下降的宽肩峰会标记 `incomplete_peak_shape`，保留曲线与评分但暂停层厚推算。关闭突发剔除时，总有效周期门限升到 1000。

多个清晰峰时，暂停自动结构估计。先看水平/垂直谱和地质信息，再在“指定峰”填入待分析峰频率。不能直接把每个峰映射成一层；窄峰须检查机械或工业噪声。

## 浅层结构能得到什么

默认采用一维覆盖层、较大阻抗反差、所选峰为基频的条件：

`f0 ≈ 1/[4 Σ(h_i/Vs_i)]`，等效均匀覆盖层 `H ≈ Vs/(4 f0)`。

程序输出 S 波单程走时、给定 Vs 范围下的等效层厚范围、Vs–厚度关系和可行条件剖面。剖面中的半空间 Vs 是用户输入先验，不是 H/V 测出的速度；地质基岩界面与共振阻抗界面也不一定相同。由时窗频散构成的厚度带不是均值置信区间。H/V 不单独给出唯一分层 Vs 或 Vs30。

例如合成示例峰为 3.016 Hz；设 Vs=200–300 m/s，则峰频率对应的等效层厚为约 16.6–24.9 m。改变 Vs 先验会改变这个厚度范围。

## 可选 Rayleigh 椭圆率试算

勾选该选项表示采用 **各向同性、基阶 Rayleigh 主导** 的明确假设。程序用现有 `disba` 求解器，搜索“一个有限层 + 固定半空间”的厚度与 Vs，显示理论/实测曲线对比和模型集合。Love 波、体波和高阶模式没有建模；这不是完整扩散场 H/V 反演。

- 试算默认关闭，不会悄悄把 H/V 当作纯 Rayleigh 椭圆率。
- RMS 理论幅值按各向同性 Rayleigh 的水平分量分配除以 `sqrt(2)`；几何平均采用相同近似，须特别核实方向效应。
- 半空间 Vs、两层 Vp/Vs、密度是固定先验。默认 160 个对数均匀随机试算；可增大次数，改变种子和先验做敏感性检查。
- 搜索使用最多 48 个频点，未再卷积观测的谱平滑过程；尖锐峰附近的幅值失配还可能来自有限频率分辨率和平滑。只作为条件试算。
- `acceptable_fit=false` 时，报告仍展示失配和试算集合，但不能视为有效结构解释。即使通过，也应结合阵列频散、钻孔或其他独立信息核验。
- 模型集合是已采样可行组合，不是后验置信区间。

## 输出位置

所选项目目录下 `output/hvsr/`：

| 文件 | 内容 |
|---|---|
| `hvsr_report.html` | 可独立打开、图片内嵌的离线报告 |
| `hvsr_curve.csv` | H/V、离散度、N/V、E/V、三分量谱 |
| `hvsr_windows.h5` | 每窗 H/V、分量谱、UTC 和统计窗索引 |
| `window_qc.csv` | 每窗接受/拒绝及原因 |
| `peaks.csv` | 候选峰与逐项质量检查 |
| `depth_vs_tradeoff.csv` | Vs 与等效深度组合；仅可靠明确峰生成 |
| `shallow_structure.json` | 结构方法、先验、状态与条件 |
| `ellipticity_trials.csv` / `ellipticity_models.json` | 可选椭圆率试算模型及失配 |
| `hvsr_summary.json` | 参数、源文件 SHA256、结果摘要 |
| `hvsr_complete.json` | 全流程完成标记，失败或中断时不保留 |

源 H5 始终只读打开。生成的新 H/V 数据和结果存放在项目目录内。

## 可重复示例与命令行

安装依赖与启动方法仍为 `install_windows.bat`、`run_windows.bat`。在主窗口打开 `examples/hvsr_single_station/project`，切换第 7 页即可查看或重新运行示例。附带示例是受控谱形合成数据，不是实际台站观测，也不是全波场结构模拟。

```bash
python run.py hvsr-inspect --folder "下载H5文件夹"
python run.py hvsr --folder "下载H5文件夹" --instrument-id "BW.MGS01..HH" --output "hvsr_result" --hvsr-settings "templates/hvsr_settings.json"
python run.py hvsr --project "examples/hvsr_single_station/project"
python run.py hvsr-example --directory "examples/hvsr_new_demo"
```

仪器 ID 使用检查结果中的精确字符串，本次真实验证使用 `BW.MGS01..HH`；实际位置代码和通道前缀以数据为准。H/V 参数文件既可以是直接参数字典，也可以是含 `folder`、`instrument_id`、`settings` 的项目文件；相对文件夹以参数文件所在目录解释。

依据：SESAME H/V Guidelines（https://sesame.geopsy.org/Papers/HV_User_Guidelines.pdf）；disba 官方文档（https://keurfonluu.github.io/disba/）。

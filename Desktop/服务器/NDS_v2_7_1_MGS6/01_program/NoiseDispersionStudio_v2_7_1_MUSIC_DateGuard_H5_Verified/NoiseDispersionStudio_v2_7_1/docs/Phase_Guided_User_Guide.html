整段共同记录 → 逐频 Goertzel → 相位筛窗 → 分支复数叠加

第6页默认自动使用所选曲线涉及的每对台站的完整共同记录。无需填写开始或结束时间。旧版开始/结束UTC只是手动截取记录区间，与单窗长度无关；旧配置没有time_mode时，界面迁移为全部记录模式。可选调试区间放在折叠区域，必须明确选择自定义模式才生效。

处理顺序

  1. 从已导入波形的真实UTC头信息读取记录范围，校正时钟偏移；每对台站独立确定共同起点与终点。默认仅把共同起点顺延600秒，沿用用户提供的MATLAB稳定时间，可以改为0。不会借用其他台站对的较短共同范围。
  2. 各台站执行声明的仪器响应校正、重采样及带通滤波，保持缺测的原UTC位置。分块处理并使用磁盘数组，降低长记录的内存需求；滤波边缘和缺测窗口不参与叠加。
  3. 对于每个曲线频点f，用T=N/f和滑动Δt=M/f计算时窗，取整为采样点。默认每窗20周期、每次滑动1周期，仅处理完整滑窗；末尾不足一个滑动步长的余数不会额外增设窗口，与附件一致。
  4. 窗口去均值，执行Goertzel，形成C=G目标·conj(G参考)。默认取最近DFT频点k=round(f·n/fs)、fk=k·fs/n，与附件一致；界面同时显示曲线频率与实际fk。精确频率模式直接计算f。窗函数默认矩形，可选Hann。
  5. 默认先筛除幅值与相邻窗口突变异常，门限为median+5·1.4826·MAD；MAD为0时用5·median。突变统计不含人为添加的第一个零。取消幅值复选框时仅标记这些异常。
  6. 按原始互谱相位≥0°与<0°分开筛选和累加，不把负分支取共轭或反号。曲线模式使用该频点的速度、台距、源相位和CCF时延分支给出的相位范围；附件原门限模式使用每个相位分支的初叠加相位±90°。
  7. 各分支最终相位为arg(ΣC)，另输出arg(ΣC/|C|)用于检查幅值权重。所有保留窗口进入求和。两分支完整结果均保存；曲线对比使用预测相位同号分支。

相位的正负号分组与CCF正/负时延分支不是同一种分类，也不能独立证明传播方向。曲线源相位及整数周期N沿用原曲线，周期别名仍无法由原台站对的相同相位门限区分。

如何运行

  1. 打开已完成候选枚举的项目，确认output含conditional_dispersion.csv、pairs.csv与measured_phase_segments.csv，原波形已导入canonical并有stations.csv。
  2. 第6页选择曲线编号，留空为全部；检查稳定时间、每窗周期数、滑动周期数及窗长预览。
  3. 保留曲线引导模式并设置相位容差，点击“处理全部记录并叠加”或本页底部“一键相位筛选与叠加”。无需手填日期。
  4. 报告显示每对台站实际处理UTC范围、逐频窗长、全部保留窗数与两分支最终复数和。记录不足一个时窗会明确显示无结果，不编造相位。

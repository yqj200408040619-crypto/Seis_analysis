# v2.5.5 真实数据全流程与成对反演

新增 `ndstudio.real_compare`，只调用程序的下载审计、导入、预处理、扫描、错时对照、周期枚举、相位处理与反演模块。逐阶段保存 `real_compare_checkpoint.json`。原始H5必须由程序的 `array-select` / `fetch` 创建并完成下载。

```bash
python run.py array-select --provider GFZ --network Y7 --station A00,B02,C00,C01,C02,D02 --start 2020-10-12 --end 2020-10-16 --size 6 --anchor A00 --output TEST/array_selection.json
python run.py fetch --selection TEST/array_selection.json --output TEST/download --chunk-seconds 21600 --workers 4 --allow-missing-data
python run.py init --project TEST/project --folder TEST/download
python -m ndstudio.real_compare --workdir TEST --compare
```

本次扫描1.5–5 Hz，步长0.05 Hz、最少6点、最小带宽0.25 Hz，其余扫描和背景阈值保持默认。复现本次结果须在新项目 `config.json` 中设置这三个扫描值。默认项目原有更密网格也支持，但结果不要求逐点一致。

`phase_settings.json` 新增可选参数：

```json
{"monotonic_only":true,"prior":{"enabled":true,"extension_hz":0.1,"maximum_log_slope":3.0}}
```

升频增速按相邻实测频点严格检查，容差仅1e-8 m/s用于浮点舍入。这是本次选择约束，不声称所有真实介质均不可能存在反常频散。完整原始候选保留；修正后交接曲线再次检查。端点采用局部对数线性拟合，斜率限制为非正，外延最多0.1 Hz；所有外延行标记 `is_prior_prediction=true` / `is_model_prediction=true`，不得替代实测频散或参与反演。周期别名的外延相位可以不同，已分开建立门限，不能继续当作同一相位等价组。

方向细网格：1°、256个均匀慢度点、速度150–3500 m/s；逐频200周期Hann窗、不重叠步长。邻近三个频点(f-0.025, f, f+0.025 Hz)分别计算波束功率再平均，不平均复系数。相位筛选用中心精确频率，保留45°、候选角度范围、15%角度误差预算、0.7相干度、0.95次峰比例和25°空间残差要求。

性能修复：先按窗口切片再按台站取值，避免每一小批都复制全记录；将网格峰值邻域和高分包络检查融合为一个Numba循环。固定随机数据在粗/细全网格与原实现逐字段比较一致。逐频完成即保存相位汇总和 `phase_progress.json`；方向频点缓存可在中断后复用。

对比保留同一台站对、同一连续频带及频点，保留源相位/整周数，前后使用相同Rayleigh模态、层数、起点数、随机种子、误差标准和独立求解器。没有合格修正实测带时，反演必须跳过并输出拒绝原因。CCF相速度仍为源相位与周期条件解，方向独立平面波结果单独保存，不把它自动指定为Rayleigh模态。

## 本次实际结果与限制

- 六台站Trillium Compact 120，原生HHZ 100 Hz；96个6小时H5下载分块均通过获取审计。台距0.931–3.831 km，平均最近邻1.427 km。校正后20 Hz，每台6,912,426个样本，全导入记录长度96小时21.3秒；每台对实际共同记录及缺测掩码单独检查。
- 287个共同CCF窗中45窗通过预处理；训练25、验证20，5个合格6小时块。1.5–5 Hz扫描得到35个验证相位段、414个实测频率行。1554条源相位/周期条件候选中222条严格非增速，1332条被排除；这些周期别名不是1554条独立实测曲线。
- 冻结三条候选：P00031_b1_S0_N4、P00031_b1_S0_N5、P00032_b1_S0_N4；同一台对C02–D02，2.45–3.15 Hz，每条15点。两测量门限也不作为独立阵列证据。外延12个先验行到2.35/2.40/3.20/3.25 Hz，不升级为实测。
- 19个方向频率（含先验）共91,765次窗口评估，409次通过阵列方向质量检查，约0.446%。主要拒绝为相干不足75,470次、网格精度12,260次、近等强分离峰3,598次。原始观测的30个相位门限中，每门限最多仅1个相位接受窗，低于3窗要求；最终CCF与独立平面波连续频带均0条。
- 三条原始候选得到28个条件相容结构模型。严格修正后没有合格观测，结构反演跳过。这不是唯一真实地层解的对比，也不把外延或筛选条件当作独立观测。
- 单独相位模块控制试验关闭方向门限，不使用外延点。修正N=5曲线出现1次0.922745 m/s局部增速，被排除；两条N=4曲线保留30点。同频点最大速度改变量0.210730%；同模态、频带、层数、起点、随机种子及接受标准下，前后各20个相容模型，独立pysurf96求解器均可用。控制结果未通过最终方向筛选，不能进入最终结构解释。
- 在独立项目对同一原始H5重新导入、预处理及扫描0.2–1.5 Hz，步长0.025 Hz，其他质量阈值不变；得到0个验证相位段、0条候选。完整50台站目录中也未找到满足每个最近邻≤900 m的六台站紧凑子阵列。

输入候选波长仅约0.29–0.49 km，短于最近邻间距；这是高频空间混叠的风险提示。元数据台距约束与三倍波长的CCF条件，不等价于阵列方向估计的空间采样充分性。此次数据不能给出满足全部要求的实测修正曲线与修正后真实结构。不得为获得非空输出而降低门限。

完整回归：183通过、8跳过。新增检查覆盖周期别名外延分门限、相位参数/波形变化拒绝旧检查点、反演输入变化自动重算。严格/控制相位审计分别复算126/90个实际互谱窗，重算相位误差均0 rad；筛选掩码、分支和夹角限制一致。

## 保存及离线复核

完整结果包保存所有筛选记录、审计、前后同频点CSV、相容模型及结构层表、HTML与PNG报告、每频方向缓存、一个校正后完整H5。原始H5按四个UTC日期分别保存为DARE_v255_Raw_20201012.zip至DARE_v255_Raw_20201015.zip；原生MiniSEED与StationXML已嵌入H5，不需要另外重复保存外部mseed副本。

将结果包的project放到本机任意目录，不修改stations.csv内容；在程序目录运行：

```bash
python run.py phase-audit --folder RESULTS/real_run/project/output/phase_guided
python run.py phase-stack --project RESULTS/real_run/project --phase-settings RESULTS/real_run/project/phase_settings.json --aligned-h5 RESULTS/real_run/project/output/phase_guided/aligned_waveforms.h5 --output RESULTS/replay_strict
```

离线审计只需完整校正H5和存储窗口，不依赖旧绝对canonical路径。全流程重建则先解压四个原始数据包到新的download文件夹，再用init与本页配置重新执行；完整导入/预处理缓存可由原始H5重建。历史追溯里的绝对路径保持原貌，不能直接把它们当作迁移后的存在性保证。

检查点复用必须核对输入、配置和程序指纹，参数改变时新建输出目录。成对反演当前按输入表、选择方案、程序源文件、连续带参数指纹复用。不得将空频带标记为已完成的修正前后物理结构对比。

要离线审计相位控制试验，先在解压后的结果包目录运行 `python restore_aligned_copies.py`，再用原生 `phase-audit --folder .../phase_control`。该辅助文件只恢复同一H5的文件别名，不进行任何数值处理。

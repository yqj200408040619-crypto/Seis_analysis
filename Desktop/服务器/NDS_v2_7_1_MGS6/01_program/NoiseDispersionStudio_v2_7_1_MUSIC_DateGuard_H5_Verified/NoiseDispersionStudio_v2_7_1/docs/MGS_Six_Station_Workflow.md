# 六站原生流程

`python -m ndstudio.mgs_e2e --workdir MGS6_run`。
六台为 BW.MGS01–MGS05 和 BW.MGSBH，默认 UTC 2022-11-01 至 11-05。
只调用程序内的下载、归档核查、导入、预处理、扫描、背景对照、候选选择、MUSIC、哥泽尔低频重建和配对反演。网络失败或缺少整台仪器停止；服务器明确无数据的缺段记录在 download_gaps.json，原生预处理剔除相关窗。

仅选择速度随频率非增的曲线。原 CCF 曲线未通过三倍波长门槛时，可以只作筛窗先验，另记 prior_only_selection.json；修正前结构是条件比较，不能声称原 CCF 观测已完成物理验证。外延至 0.08 Hz 只作先验，不直接进入观测与反演。
前段和后段使用六台全部数据逐频MUSIC定向。前段不使用45°台对门槛，后段默认45°。精确 Goertzel、Hann 窗、200 周期不重叠窗，MUSIC 台对角度上限 45°，保留方向、独立窗和错时背景门槛。

若最终要输出沿波矢的真实相速度，还必须一致地处理台距投影，不能直接把台对视速度当作真实波速。
修正前后共同频带均采用一致投影，再分别反演；扩展反演仅使用修正后合格实测低频点。2000 m/s 只用于最大台距的到时范围计算，不限制后续速度。

前段无合格连续频带时，原CCF候选只作后段低频筛窗先验继续处理；后段也无合格连续频带时记录并跳过反演，不用预测值造曲线或结构。结果位于 comparison/report.html；mgs_e2e_status.json 记录实际完成状态。
需可选独立求解器：python -m pip install pysurf96==1.0.1。
--reuse-download 跳过网络请求，仍做完成性和源文件检查。中断后使用同一命令和目录续传。
